# وصف الفيتشرز: حضور وغياب الموظفين + نظام قبض الموظفين

لو عايزين نخلي الـ CRM شامل، دول ممكن تكتب الفيتشر دي كده (للعروض / للعميل / للتطوير).

---

## ١- حضور وغياب الموظفين (Attendance)

### اللي الفيتشر بيعمله
- **تسجيل حضور يومي:** كل موظف يقدر يسجل دخول (Check-in) وخروج (Check-out) من النظام، أو الـ Admin/المشرف يسجل عنه.
- **تسجيل الغياب:** اختيار يوم معين كـ غائب (بدون حضور) مع إمكانية سبب اختياري (إجازة، مرض، غياب بدون إذن، إلخ).
- **التأخير:** لو في وقت دخول مفروض، النظام يقدر يحسب تأخير (بالدقائق) ويربطه باليوم.
- **تقارير:** تقرير حضور/غياب لموظف معين خلال فترة، أو تقرير يوم معين لكل الموظفين، مع إمكانية تصدير (Excel).
- **تنبيهات (اختياري):** تنبيه للمشرف أو الـ Admin لو موظف غاب X أيام متتالية أو تأخر بشكل متكرر.

### بيانات أساسية
- **سجل الحضور:** موظف، تاريخ، وقت الدخول، وقت الخروج، حالة (حاضر / غائب / إجازة / نصف يوم)، ملاحظات.
- **إعدادات (اختياري):** وقت الدخول الرسمي، وقت الخروج الرسمي، أيام العمل الأسبوعية.

### من يستخدمه
- الموظف: تسجيل دخوله وخروجه (أو المشرف يسجل له).
- المشرف / Admin: عرض وتعديل سجلات الجميع، تقارير الحضور والغياب.

---

## ٢- نظام قبض الموظفين (Payroll / المستحقات والقبض)

### اللي الفيتشر بيعمله
- **تسجيل القبض:** لكل موظف نقدر نسجل إنه "قبض" مبلغ معين في تاريخ معين، مع نوع القبض (مرتب، عمولة، مكافأة، سلفة، بدل، إلخ).
- **تفاصيل كل قبضة:** المبلغ، التاريخ، النوع (مرتب / عمولة / مكافأة / سلفة / خصم / استرداد)، ملاحظات، واختياري ربطها بشهر معين (مثلاً مرتب يناير).
- **عرض سجل القبض:** قائمة بكل اللي الموظف قبضه خلال فترة، مع المجموع.
- **تقارير:** تقرير شهري أو سنوي للي قبضه كل موظف، أو تقرير لموظف واحد (كل القبضات + الإجمالي)، مع إمكانية تصدير (Excel).
- **ربط اختياري بالحضور:** تقرير يوضح أيام الحضور/الغياب في نفس الفترة مع إجمالي القبض (مفيد للرواتب الشهرية).

### بيانات أساسية
- **سجل القبض (Payroll Entry):** موظف، تاريخ القبض، المبلغ، نوع القبض (مرتب / عمولة / مكافأة / سلفة / خصم / غير ذلك)، شهر المرجع (اختياري)، ملاحظات.
- **أنواع ثابتة (اختياري):** مرتب، عمولة، مكافأة، سلفة، خصم، استرداد، بدل — أو الإدخال حر (نص).

### من يستخدمه
- الـ Admin أو مدير مالي: إضافة وتعديل سجلات القبض، عرض التقارير.
- المشرف (اختياري): عرض تقارير فريقه فقط حسب الصلاحيات.
- الموظف (اختياري): عرض "لي أنا قبضته" فقط بدون تعديل.

---

## ملخص للعرض على العميل

- **حضور وغياب:** تسجيل يومي لحضور وغياب الموظفين مع تقارير وتنبيهات؛ النظام يبقى شامل لإدارة الفريق.
- **نظام قبض الموظفين:** تسجيل كامل للي قبضه كل موظف (مرتب، عمولات، مكافآت، سلف، خصومات) مع تاريخ وتقارير شهرية/سنوية؛ النظام يبقى شامل للإدارة المالية للفريق.
